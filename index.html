Deterministic Microservices

The 7 Senses of AgentMesh

Eliminate token waste, syntax breakage, and dangerous local execution by offloading heavy lifting to dedicated microservices.

symbol-graph-svc

Rust / Tree-sitter

The code GPS. Instantly resolves definitions, references, and full cross-file call graphs across monorepos in <20ms without burning LLM context tokens.

Tools: find_definition, build_call_graph

sandbox-pool-svc

Go / CoW MicroVM

The disposable playground. Instant 3ms Copy-on-Write snapshotting and execution runner. Agents test 5 risky hypotheses concurrently with zero host risk.

Tools: create_sandbox, snapshot_diff

test-oracle-svc

Python / Git

The smart detective. Computes precise test impact matrices from git diffs and runs automated bisection to locate the exact commit that introduced a failure.

Tools: analyze_impact, run_bisect

ast-patcher-svc

Rust / Tree-sitter

The laser scalpel. Surgical AST transformations that guarantee zero syntax errors, missing brackets, or whitespace diff collisions.

Tools: apply_ast_patch, rename_symbol

episodic-memory-svc

Python / FastAPI / SQLite

The long-term diary. Knowledge graph and hybrid vector memory retaining cross-session learnings, user preferences, and repository architectural patterns.

Tools: store_episode, graph_query

visual-eval-svc

Node / Playwright

The visual eyes. Headless browser engine that performs pixel-diffing, layout shift inspection, and WCAG accessibility auditing on generated UI.

Tools: render_page, diff_snapshots

safety-broker-svc

Go / Merkle Audits

The bouncer and vault. Intercepts destructive actions, injects ephemeral secrets safely without leaking to prompt transcripts, and generates tamper-proof SHA-256 Merkle audit logs.

Tools: evaluate_action, verify_victory
